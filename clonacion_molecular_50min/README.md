# Clonación Molecular: Vectores y Aplicaciones

Clase visual de 50 minutos para quinto semestre. Sigue el orden de las diapositivas de 2022 y amplía vectores, ensamblaje, verificación e interpretación de simulaciones.

## Descargar la clase

- [PowerPoint editable — 28 diapositivas](Clonacion_molecular_50min.pptx)
- [PDF para proyectar](Clonacion_molecular_50min.pdf)
- [PowerPoint con seis anexos de consulta](Clonacion_molecular_50min_con_anexos.pptx)
- [PDF completo con anexos](Clonacion_molecular_50min_con_anexos.pdf)
- [Guía docente: tiempos, notas, respuestas y bibliografía enlazada](Guia_docente_Clonacion_50min.md)

En GitHub, abrir el archivo y usar **Download raw file** para descargarlo. También se puede descargar el repositorio desde **Code → Download ZIP**.

Incluye mapas de vectores, restricción–ligación, comparación Golden Gate/Gibson, cálculo de relación molar, selección y cribado, INSDC, digestión virtual y comprobación de marco de lectura. Hay 26 diapositivas de contenido y dos de bibliografía; los tiempos aparecen solo en la guía.

Las figuras son originales y editables. Las secuencias y mapas de los ejercicios son modelos didácticos; no representan resultados experimentales. Los PDF originales proporcionados por la usuaria no se redistribuyen en esta carpeta. Las fuentes incluyen libros, un protocolo de 2023 y una aplicación publicada en 2026.
